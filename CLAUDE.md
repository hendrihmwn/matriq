# MATRIQ (MAterial TRaining Quiz) — project context

## Purpose
A set of AI-powered learning tools for any topic and any level (school to professional):
material summaries, quizzes, fill-in-the-blank exercises, flashcards, step-by-step guides,
and coding exercises. Content is generated by Claude Code through **skills**, then delivered
as interactive pages (artifact/HTML) or sent to a Telegram group (daily quiz + leaderboard).

## Key decisions
- **No LLM API.** Content is generated with Claude Code (interactive or headless `claude -p`)
  using a Claude subscription account. Scheduled runs use cron.
- Content rules and formats live as **skills** in `.claude/skills/matriq-*/`
  ("prompts as code"). Each skill is self-contained so it can be uploaded to claude.ai on its own.
- Interactive pages are single self-contained HTML files (no external libraries or network
  requests), safe to open as artifacts.
- The Telegram bot does not call any AI; it only reads `output/quiz-YYYY-MM-DD.json`.
- Telegram questions are sent as **non-anonymous** quiz polls (so answers can be recorded).
- Bot storage: SQLite (`quiz.db`).

## Skills
| Skill | Purpose |
|-------|---------|
| `matriq-quiz` | `telegram` mode (JSON/MD for the bot) and `quiz` mode (interactive mixed quiz) |
| `matriq-material` | material summary: A4 textbook-style summary page, or a Telegram message |
| `matriq-flashcards` | flashcard deck with Easy/Medium/Hard self-rating |
| `matriq-fill-blank` | fill-in-the-blank exercise with a running score |
| `matriq-stepper` | step-by-step guide |
| `matriq-code` | coding exercises with an in-browser JavaScript runner |

All skills: if the topic is missing, ask first (in headless runs: stop and report it).

## Structure
- `bot.py` — Telegram bot (python-telegram-bot v21, JobQueue sends at 08:00 Mon–Fri,
  commands /start /quiz /leaderboard /myscore)
- `.claude/skills/matriq-quiz/` — `SKILL.md`, `modes/` (telegram, quiz, html-rules),
  `history.json` (Telegram question history to avoid repeats)
- `.claude/skills/matriq-fill-blank/`, `matriq-flashcards/`, `matriq-stepper/` — each has its own
  copy of `html-rules.md` (update all four copies when the page rules change)
- `.claude/skills/matriq-code/` — `runner.js` (JavaScript runner in a Web Worker, copied verbatim
  into each page); other languages have no runner (predict-the-output / find-the-bug with an answer key)
- `.claude/skills/matriq-material/` — `modes/` (page, telegram) + `send_telegram.sh`
- `docs/` — (optional) source documents for material/questions
- `output/` — generated files: daily quiz JSON/MD and HTML pages

## Flow
- **Interactive:** `/matriq-<skill> topic: ...` → `output/<type>-YYYY-MM-DD-<topic>.html`
  → published as an artifact.
- **Telegram daily quiz:** cron 07:00 → `claude -p "/matriq-quiz topik: ..." --allowedTools "Read,Write"`
  → JSON → bot.py sends at 08:00 → answers recorded → /leaderboard
