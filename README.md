# MATRIQ — Material Training Quiz

AI-powered learning tools for any topic: material summaries, quizzes, fill-in-the-blank
exercises, flashcards, step-by-step guides, and coding exercises. All content is generated by
Claude Code through **skills** (using a subscription account, no LLM API), and then either:

- opened as an **interactive page** (an artifact on claude.ai or an HTML file in a browser), or
- sent to a **Telegram group** as a daily quiz with a leaderboard.

## Skills

| Command | Result |
|---------|--------|
| `/matriq-material topic: Bumi level: SMP` | A4 summary page in a study-book style |
| `/matriq-quiz mode: quiz topic: Kubernetes` | Interactive quiz (multiple choice, true/false, multiple select) |
| `/matriq-flashcards topic: Git count: 12` | Flashcards with a flip animation and self-rating |
| `/matriq-fill-blank topic: Sistem Pernapasan` | Fill-in-the-blank exercise with a running score |
| `/matriq-stepper topic: Deploying to a server` | Step-by-step guide |
| `/matriq-code topic: if else` | Coding exercises with an in-browser JavaScript runner |
| `/matriq-quiz topik: Linux` | 5 questions for the Telegram bot (`output/quiz-YYYY-MM-DD.json`) |
| `/matriq-material mode: telegram topic: SSH key` | Summary sent as a Telegram message |

Common arguments: `topic:` (required; Claude asks if it is missing), `count:`, `level:`,
`lang: id|en` (content defaults to Bahasa Indonesia). You can also paste material directly
(`materi: ...`) or put source documents in `docs/`.

Output is saved in `output/`. In Claude Code, HTML pages are published as artifacts when
available; otherwise open the file in a browser.

### Using the skills on claude.ai
Zip each folder in `.claude/skills/matriq-*` separately and upload it in the Skills settings.

## Telegram daily quiz

```
cron 07:00 ──► claude -p "/matriq-quiz ..." ──► output/quiz-YYYY-MM-DD.json
                                                      │
bot.py (always running) ── 08:00 send quiz polls ◄────┘
        └── record answers in quiz.db ──► /leaderboard
```

### Setup
1. Create a bot with **@BotFather** and keep its token.
2. Add the bot to your group. Find the group's chat ID (e.g. send a message in the group,
   then open `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Install and configure:
   ```bash
   pip install -r requirements.txt
   cp .env.example .env   # fill in the token and chat ID
   ```
4. Make sure Claude Code is logged in with a subscription account (`claude` → `/login`).

### Running
Question generator (crontab, Mon–Fri 07:00). The topic is required, because a headless run cannot ask:
```cron
0 7 * * 1-5 cd ~/quiz-bot && claude -p "/matriq-quiz topik: Linux networking" --allowedTools "Read,Write" >> logs/generate.log 2>&1
```

Bot (keep it running, e.g. with tmux/systemd):
```bash
python bot.py
```

Material summary to the group (optional; needs permission to run the send script):
```bash
claude -p "/matriq-material mode: telegram topic: Docker" \
  --allowedTools "Read,Write,Bash(bash .claude/skills/matriq-material/send_telegram.sh:*)"
```

### Quick test without waiting for the schedule
```bash
claude -p "/matriq-quiz topik: Git" --allowedTools "Read,Write"
python bot.py      # then type /quiz in the group
```

### Bot notes
- Polls are **non-anonymous** so answers can be recorded (the bot can see who answered).
- Telegram limits: question 300 characters, option 100, explanation 200 (truncated automatically).
- If today's quiz file is missing, the bot posts a warning to the group.
- English questions (`lang: en`) show English difficulty labels (easy/medium/hard).

## Limitations
- The `matriq-code` runner supports JavaScript only. Other languages use predict-the-output /
  find-the-bug exercises with an answer key, because artifacts cannot download runtimes such as Pyodide.
- Content is AI-generated: double-check answer keys before using them for formal assessment.
